# Research Reports

*ecnuJeff · East China Normal University*

Four short reports on memory-chip pricing, open-source culture assets, regional digital finance, and dialect use in southern Jiangxi. Each one starts from data whose source can be named, and each one states what that data cannot support.

The four pieces look unrelated. They share one habit: count something, then ask what the count does and does not prove. Where a conclusion cannot be identified from the data, the report says so instead of rounding it up.

## About

All four were written in November 2026 alongside undergraduate study at East China Normal University. Sources are public statistics, platform APIs, and one self-run questionnaire. Each file lists its own source and scope, including the limits of what the data can show.
